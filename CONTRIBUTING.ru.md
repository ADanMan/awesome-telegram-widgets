# Как добавить виджет

[English](CONTRIBUTING.md) · **Русский**

Подойдут игры, инструменты и эксперименты в формате HTML-виджетов Telegram, которые можно запустить или изучить по исходникам.

Для каждого нового виджета обязательна прямая ссылка на оригинальный проект, бота или виджет автора. Добавьте её в обе версии README и в кнопку **Оригинал** в боте. Это правило действует и для адаптаций.

## Предложить находку

[Откройте заявку](https://github.com/ADanMan/awesome-telegram-widgets/issues/new?template=suggest-widget.md). Укажите название, автора и публичную ссылку. Опишите одно действие внутри сообщения, команду запуска, поддерживаемые клиенты и требования к настройке, аккаунту или оплате. Отметьте использование демоданных.

## Прислать pull request

1. Проверьте, есть ли виджет в каталоге. Добавьте строку в английский и русский README со ссылкой на оригинальный проект и, если доступен, на бота.
2. Укажите версию Telegram, действие и результат проверки. Если изучили только исходники, напишите об этом.
3. На скриншотах оставьте только виджет. Обрежьте имена, соседние чаты и учётные данные.
4. При добавлении кода приложите исходники, имя автора и лицензию, разрешающую распространение. HTML должен быть самодостаточным и укладываться в [лимиты Telegram](https://core.telegram.org/bots/widgets). Для виджета с отдельным сервером можно дать прямую ссылку на бота автора.
